**Golden validity vs Δ:** applied mapping remains **Δ = −8**. `iq_compare` does **not** remap by Δ. It now aligns on **DU slot** from `iq_meta.first_du_sfn/first_du_slot` (fallback `MANIFEST.json` `first_du`, then derived from `last_du_* + slots_written`) and maps slots to samples through `tx_index.jsonl` (`du_sfn`,`du_slot`) when present. It normalizes by the shortest sample offset, reports that offset, and **fails** unless the DU-slot overlap covers the full golden range (`--min-overlap-slots`, default = full range). Partial-slot or shifted compares fail; there is no sequential-sample fallback for slot-labelled dumps.

**−1052 is excluded from captures:** the null radio now holds the dump until the observable residual `du_abs − radio_abs` (wrapped mod `256 × slots_per_frame` = 5120) has been constant for `dump_start_stable_slots` (default **100**) consecutive slots. Skipped slots are counted in `iq_meta.dump.prestart_dropped_buffers`; `iq_meta.dump` also records `dump_started`, `dump_start_stable_slots`, `dump_start_delta`, `first_du_sfn`, `first_du_slot`, and `first_dump_sample_offset`. Restart 2’s −1052 is at DU_end **68.0**, i.e. **0.104 s** after RU align — before the 1 s (25 s run) and 3 s (600 s run) warm-ups. The gate pushes the first dumped slot to ≈**70.2 / 194.1 / 170.1** for baseline / b40 / b100 (100 stable slots after the first stable block), so the outlier precedes any gated capture. The existing goldens were captured **before** the gate (`first_du` 65.18 / 189.13 / 165.11), so the baseline golden’s first slot is earlier than 68.0; regenerate the goldens with the gate before relying on this claim for stored data (see `docs/OPEN_QUESTIONS.md`).

### IQ dump ~32 MiB stop [MEASURED] — silent shm full (fixed)

During the 600 s run, `port0/1.cf32` froze at ~32 MiB with `mtime` = start while KPIs continued. Cause: Docker default `ShmSize=64 MiB`; `df /dev/shm` = **100% full**; `ofstream` ignored `failbit` → silent stop.

**Fix** (image `m1` @ dumpfix rebuild, 250 s warm slim `gnb ru_emulator`):
- compose `shm_size: ${PROTORU_SHM_SIZE:-2gb}`
- `max_dump_slots` / `max_dump_bytes` in `device_args` (profile default **4000** ≈ 2 s)
- log `dump stop — max_dump_slots reached at DU slot N.M`; `iq_meta.dump.{cap_reached,stop_reason,last_du_*,slots_written,dropped_buffers}`
- `tx_index` records `du_sfn`/`du_slot` (GPS/OFH) + `radio_*`; `iq_compare` aligns by DU slot via `iq_meta`/`tx_index` and fails on insufficient overlap or mismatched sample counts
- `dump_start_stable_slots` (default **100**) holds the dump until the DU/OFH-vs-radio residual is constant; see *−1052 is excluded from captures* above

Verified 15 s smoke: shm 2.0G used 705M; cap at 4000 slots, `last_du_sfn=78`, log + meta OK.

**`iq_compare` DU-slot alignment.** `tools/iq_compare/iq_compare.py` reads the first/last DU slot from `iq_meta.json` (new `first_du_sfn/first_du_slot`; fallback `MANIFEST.json` `first_du`; fallback `last_du_* + slots_written`), maps DU slots to samples through `tx_index.jsonl`, normalizes by the shortest offset, reports the offset/overlap, and fails if the overlap is less than the full golden range (`--min-overlap-slots`, default `-1` = full range). Unit tests: `tools/iq_compare/test_iq_compare.py` (one-slot shift pass, too-short fail `FAIL: DU slot overlap 3 < required 4`, min-override pass, mismatched-sample fail); all 4 pass with `python3 -m unittest discover -s tools/iq_compare -p 'test_*.py' -v`. Golden-vs-itself sanity passes for baseline (4000 slots, n=46,079,400), b40 (2000, n=46,078,800), b100 (800, n=49,148,800).

**Δ dump-start gate.** `dump_start_stable_slots` (default **100**) holds `tx_dump` until the observable residual `du_abs − radio_abs` (wrapped mod `256 × slots_per_frame` = 5120) is constant for N consecutive slots; the first written block sets `first_du_sfn/first_du_slot/first_dump_sample_offset`, and skipped blocks are counted in `prestart_dropped_buffers`. ## Appendix: Golden hosting — Zenodo proposal (no upload performed)
