Date: 2026-11-13

## Scope notes

- Emulator mode (no `sdr:`) is **M0-only**. It does not run the low-PHY path that produces golden IQ.
- M1 uses **`device_driver: null`** (`lib/radio/null/`) so TX IQ is dumped after low-PHY.
